🌷 Florería Floraste

📌 Descripción del proyecto

Florería Floraste es una página web desarrollada para una florería, donde los usuarios pueden conocer los productos disponibles y explorar diferentes opciones de ramos de flores.

El sitio cuenta con un diseño delicado y minimalista, utilizando colores pastel para transmitir una estética cálida y agradable.

✨ Funcionalidades

🏠 Inicio: página principal con información y contenido destacado.

💐 Ramos: catálogo de productos disponibles.

🛒 Carrito de compras: permite agregar productos y visualizar el carrito.

📩 Contacto: sección destinada a la comunicación con la florería.

🌤️ Clima: sección que muestra información del clima en Catamarca.

🛠️ Tecnologías utilizadas

HTML5

CSS3

JavaScript

Bootstrap 5.3.8

API de OpenWeatherMap para consultar el clima.

📁 Estructura del proyecto

index.html: página principal.

pages/: contiene las páginas de Ramos y Contacto.

pagescss/: contiene los archivos de estilos CSS.

pagesjs/ o JavaScript/: contiene los archivos JavaScript.
